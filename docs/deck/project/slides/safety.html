Each kind of change has a safety level

L0

Report

Findings in a report

Needs: nothing

L1

Config patch

Edit Claude’s instruction file, or turn off an unused add-on

Needs: a person to approve the change

L2

Same meaning

Rearrange requests so more is cached; the model sees the same thing

Needs: logging first, then a few sessions; undone if worse

L3

Changes behaviour

Shorten long command output, use a cheaper model, limit thinking

Needs: each project to opt in; a few sessions first; quality must hold

A team sets the highest level allowed; the default is L1. Today’s prototype is L0: it only reports.

Shadow: work out the change and log what would have happened, without sending it. Canary: apply it to a small share of sessions first. If quality signals get worse, it rolls back on its own. L3 changes what the model sees, so it needs opt-in per repository as well as team policy.
