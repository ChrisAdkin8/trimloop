Trimloop

Find out where your tokens go, and which habits cost you the most.

For Claude Code, Anthropic’s AI coding assistant · an early prototype

Trimloop reads the session logs Claude Code keeps on your machine, works out where the tokens went, and says which changes to how you work would save the most. The name: it trims wasted tokens in a loop of detect, recommend, measure, repeat.
