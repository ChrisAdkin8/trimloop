Nudges warn you while you work

1

A status line

Below your prompt: the session’s size and cost. Near the cache’s end, a countdown; after it, what the next message will cost.

2

Size messages

Once when a session passes 200,000 tokens, and again at 500,000.

3

A pause before sending

In a big session whose cache has expired, it stops your first message once and shows what sending it will cost.

trimloop setup

Prints the settings to add

trimloop setup --write FILE

Adds them, after saving a backup

trimloop setup --check

Checks it is all working

Hooks are commands Claude Code runs after each reply and before each message. Trimloop uses them for the size messages and the pause.

The report looks back; the nudges act at the moment the money is about to be spent. The pause applies to sessions over 500,000 tokens after a break long enough for the cache to expire. The message is not sent; send it again to go ahead, or /clear first to start fresh. If you already have your own status line, setup --write changes nothing unless you add --replace-statusline.
