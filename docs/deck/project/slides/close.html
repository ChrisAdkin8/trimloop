trimloop setup

Turn on the nudges inside Claude Code

trimloop --since 7d

Measure: did last week’s change work? Then repeat

Or add trimloop’s plugin (an add-on) to Claude Code and just ask “where did my tokens go?”. Read README.md first, then docs/measurements.md for the method and ROADMAP.md for what comes next.

The four commands retrace the deck. Start with the short summary, pick the top recommendation, change that one habit, then run trimloop --since with the day you changed it to see whether it worked. The plugin needs trimloop installed; it adds a skill so Claude runs trimloop and explains the result.
