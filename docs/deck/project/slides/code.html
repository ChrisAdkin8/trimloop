Written in Go, a programming language. Names in code type are folders and functions in the repository.

The command in cmd/trimloop wires these together. Each module has a narrow front door: Load gives sessions, Analyse gives one Results value, and the summary, text, web page and JSON all render that same value. docs/state-machines.md lists everything the code remembers between steps.
