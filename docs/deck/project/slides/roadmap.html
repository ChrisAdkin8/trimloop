Team view

Safe changes

Makes level-2 changes itself: a few sessions first, watching quality

M4

More tools

More coding assistants; level-3 changes for projects that opt in

M0 to M4 are milestones, each useful on its own. The order builds trust: reading logs first, changing requests last. Levels 1–3 are the previous slide’s safety levels.

M0 is what exists today. A gateway is a service that routes a team’s model requests, such as LiteLLM; the sidecar sits beside it and watches. The team collector receives fingerprints and counts, never code. Each milestone is in ROADMAP.md, and each decision behind it in docs/adr.
