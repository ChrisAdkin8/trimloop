Cached history is cheap, until it expires

Write

The first turn stores the conversation. This costs more than sending it normally.

Read

Later turns reuse it, at a tenth of the normal price or less.

Break

You step away for longer than 5 minutes or an hour.

Expired

The next turn writes the whole conversation again, at the dear rate.

Claude Code picks how long the cache lasts: usually an hour when you chat, 5 minutes for sub-agents (helpers Claude starts for side tasks) and for runs started from a program. So long breaks and short waits both cost money.

The cache is Anthropic keeping the start of a recent request so the next one can reuse it. A cache read is cheap; a cache write is dearer than plain input. After it expires, the next request pays the write price on everything again. In a session of 500,000 tokens that is a big bill for one message.
