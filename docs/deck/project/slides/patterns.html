It looks for nine kinds of waste

P19

Long sessions

Every turn re-sends it all, so each message costs more.

P09

Long breaks

An hour away, the cache expires and is paid for again.

P02

Short waits

5-minute caches lost while a slow command runs.

P04

Tool output

Big command output and file reads, re-sent every turn.

P07

Fixed load

Instructions, tool lists and memory files sent with every request.

P13

Model choice

A dearer model than the work needs, or an older, dearer version.

P14

Effort level

Effort is how long it thinks; the top levels think far more.

P01

Model switches

A new model mid-session stores the whole conversation again.

P12

Replies cut off

The laptop slept or the network failed, so it was sent again.

Top row: size and time, the re-sending and cache costs from the start. Middle row: what each request carries. Bottom row: model and settings. The codes (P19 and so on) number the patterns in docs/patterns.md.

Each finding has a pattern code, P01 to P19, used across all the design documents. The full catalogue in docs/patterns.md has more patterns than the prototype detects today. Besides these, the report shows spend by project, skill, plugin and MCP server.
