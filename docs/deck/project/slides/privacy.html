Everything stays on your machine

Reads local logs. Sends nothing.

Files it keeps hold numbers only. Reports show session titles (Claude Code’s names for your chats) and project names, so check one before you share it: --no-titles hides the titles.

For teams, the plan is to share keyed hashes: fingerprints only the customer’s own key can make. Never code or names.

Everything lives under ~/.trimloop and is readable by you only. The backups can hold API keys from your Claude Code settings, so delete old ones when you no longer need them. The keyed-hash design for teams is in ADRs 0004, 0011 and 0019.
