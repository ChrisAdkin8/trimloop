Orange: built today

Today you make each change yourself. The plan: collect every request, spot the waste, advise, make the safe changes for you, and measure again.

Principles

Local-first

Prompts can hold code and secrets; they stay on your machine.

Observe before acting

Advice first; a change is tried on a few, then on all.

Quality is a constraint

A saving that makes the assistant worse is not a saving.

Neutral

The same rules for every coding assistant and AI company.

The plan · designed, not built yet

Next: it makes the safe changes itself

The loop of recommend, apply, measure is the core of the planned product. The wider product is design only. It would capture requests from any coding agent or gateway (Claude Code, Codex, Cursor; LiteLLM, Portkey), detect waste, recommend fixes across a whole team, and apply the safe ones automatically, with measurement and rollback. Shadow mode means a change is worked out and logged but not applied.
