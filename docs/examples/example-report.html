Words used in this report

Show the words
Token
The unit Claude is paid by: a word-piece of about four characters.
Turn
One request to Claude and its reply. One prompt from you can take many turns while Claude works.
Session
One Claude Code conversation, with any sub-agents it started. Every turn sends the whole session so far.
Session size
How many tokens a turn sends: everything said so far, including tool output.
Cache
A saved copy of the session that Claude can re-read cheaply. It expires after 5 minutes or 1 hour without use.
Effort level
How hard Claude is asked to think before answering: low, medium, high, xhigh or max. Higher levels write more output, which costs more, and suit hard problems.
Compact
Replace the session with a short summary (/compact in Claude Code).
Sub-agent
A helper Claude starts for a side task; only its final report returns to the main session.
MCP server
A connected tool provider, such as a browser or an issue tracker.
System prompt
Claude Code's own instructions to Claude, sent at the start of every request.
Memory file
A file such as CLAUDE.md whose instructions are added to every session.
Likely, up to
"Likely" is an estimate for one change; "up to" is the most it could save.

Costs are estimates at list prices (anthropic-list-2026-11-08); tool output and added text are sized at about 4 characters per token. Savings are estimates and overlap.
